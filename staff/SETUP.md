# 직원 전용 진열 분석 배포

현재 코드는 기존 GitHub Pages에 추가하는 화면과 별도의 Cloudflare Worker입니다. 기존 AI 셰프 Worker는 변경하지 않습니다. 화면 파일만 업로드하면 로그인·AI 분석·공유 저장은 작동하지 않습니다. 아래 서버 설정을 완료해야 합니다.

## 1. 별도 Worker와 저장소 준비

Cloudflare 웹 편집기를 사용하는 경우에는 기본 `worker.js` 전체를 `staff/worker-dashboard.js` 내용으로 교체하고 Deploy를 누릅니다. 이 파일은 `node staff/build-dashboard.mjs`로 생성하는 단일 파일 버전이며, 별도의 import 파일 추가가 필요 없습니다. 기본 배포 후에는 루트 주소 또는 `/health`에 서버 배포 안내가 표시됩니다. 아래 저장소·비밀값·요청 제한 바인딩은 별도로 설정해야 합니다.

Cloudflare 계정에서 D1 데이터베이스 `obok-shelf-records`, 비공개 R2 버킷 `obok-shelf-photos`를 만듭니다. R2 공개 접근은 켜지 않습니다. 실제 D1 ID를 `wrangler.jsonc`에 입력하고, `schema.sql`을 D1에서 실행합니다. 본 폴더에서 `wrangler deploy`로 별도 Worker를 배포합니다. Wrangler가 없는 환경에서는 설치 후 실행합니다. 유효한 구독과 권한이 필요합니다.

배포 후 DB, PHOTOS, LOGIN_LIMITER, ANALYSIS_LIMITER 바인딩을 확인합니다. 로그인은 IP별 1분에 5회, 분석·저장은 직원별 1분에 6회 제한입니다. Cloudflare의 분산 제한은 과금 상한을 보장하지 않으므로 AI 제공자에서도 사용 예산을 설정합니다.

## 2. 서버 비밀값

Worker 설정의 Secrets에 아래 값을 입력합니다. GitHub나 `config.js`에 넣지 않습니다.

- `OPENAI_API_KEY`: 사진 분석 권한과 결제가 설정된 키
- `OPENAI_MODEL`: 이미지 입력과 Responses API의 JSON schema 출력을 지원하는 사용 가능 모델. 기존 AI 셰프와 같은 계정에서 모델을 선택할 수 있으나 실제 접근 권한 확인이 필요합니다.
- `STAFF_SESSION_SECRET`: 32자 이상의 충분히 무작위인 비밀값. 관리자 PC의 `python -c "import secrets; print(secrets.token_urlsafe(48))"`로 생성할 수 있습니다.
- `STAFF_USERS_JSON`: `python staff/create-account.py`로 생성한 직원 계정 배열. 여러 직원은 객체를 하나의 배열로 합칩니다. 비밀번호 원문은 저장하지 않습니다. 비활성화할 계정에는 `"disabled":true`를 넣습니다. 계정 변경은 이후 요청에 즉시 적용됩니다.

세션은 8시간이며 브라우저 메모리에만 유지됩니다. 새로고침하면 다시 로그인합니다. 개별 로그아웃은 브라우저 토큰 제거이고, 전 세션 폐기는 세션 비밀값 교체로 처리합니다.

## 3. 홈페이지 연결

`staff/config.js`의 `window.OBOK_STAFF_API`를 **실제로 배포한 직원용 Worker HTTPS 주소**로 설정합니다. 예시 주소나 기존 AI 셰프 주소를 임의로 넣지 않습니다. 별도 도메인을 연결하면 해당 주소를 씁니다. 홈페이지 Origin이 달라지면 ALLOWED_ORIGINS도 수정합니다.

홈페이지 루트 `index.html`에는 PC 메뉴와 모바일에서도 접근 가능한 하단 링크를 추가했습니다. 변경된 index.html과 staff 폴더를 기존 GitHub 저장소에 반영합니다. 서버 소스가 공개되어도 비밀값은 포함되지 않으며 데이터베이스·사진·분석 API는 서버에서 직원 인증을 요구합니다.

## 4. 첫 사용 확인

1. 미로그인 상태의 /records, /analyze, /photos 접근이 거부되는지 확인합니다.
2. 직원 계정으로 로그인해 간장 진열대 1~2장을 선택합니다. 사진은 브라우저에서 JPG로 변환하고 긴 변 2000px 이하로 줄여 전송합니다. HEIC는 변환 후 선택합니다.
3. 같은 진열대의 이어지는 사진인지 별도 구역인지 선택합니다. 중복 영역이 애매하면 재촬영합니다.
4. AI 표시 위치와 수량을 눈으로 확인하고 오인식·누락을 수정합니다. 면수를 확인한 뒤 저장합니다.
5. 새로 로그인해 사진·수정 결과가 보존되는지 확인합니다. 직원은 본인 기록만, admin은 전체 기록을 봅니다. 목록은 최근 200건입니다.
6. 다른 직원 계정으로 상세 URL과 사진 URL을 열어 접근이 차단되는지 확인합니다.

## 계산·기록 기준

사진에 보이는 앞면의 수를 셉니다. 뒤쪽 재고·가로 폭·매출은 측정하지 않습니다. 샘표·몽고·오복·기타·판독 불가 5분류이며, 판독 불가도 전체 분모에 포함합니다. 빈 진열 공간은 제외합니다. 점유율은 원수량으로 계산하고 소수점 1자리로 표시하므로 표시 합계가 100.0%와 약간 다를 수 있습니다.

AI 결과는 추정값입니다. 흐릿한 라벨, 곡면, 가려짐, 중복 사진은 오류가 날 수 있습니다. AI의 최초 결과는 사진 해시·매장정보와 함께 서명하여 직원 수정본과 별도로 저장합니다. 분석 서명 유효시간은 4시간입니다. 저장된 기록은 상세 확인과 CSV 내보내기를 지원하며 수정 저장은 지원하지 않습니다. 새 조사는 새 사진 선택 후 분석합니다.

직접 촬영한 매장 사진으로 브랜드·수량·중복 제거 정확성을 검증한 뒤 직원에게 배포하세요. 현재 작업 환경에서는 실제 AI 계정, 직원 계정, Cloudflare 저장소가 없어 실서비스 시험을 수행하지 않았습니다.

## 비용·운영

AI 사진 분석 요청과 Cloudflare Workers/D1/R2 사용료가 발생할 수 있습니다. 분석 비용은 모델·사진 크기·호출량에 따라 달라집니다. 직원 계정 발급/폐기와 월별 비용 확인 담당자를 지정하고, 사진 보관기간에 맞춰 D1 레코드와 해당 R2 객체를 함께 정리합니다. 현재 자동 삭제·계정 관리 화면은 포함하지 않습니다.
