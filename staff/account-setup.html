관리자 비밀번호 설정

아이디 obokadmin · 표시 이름 영업관리자

이 파일을 내려받아 Chrome에서 여세요. 비밀번호는 이 컴퓨터 안에서만 처리되며 외부로 전송되지 않습니다.

Cloudflare 직원용 서버 Settings → Add variable

  • Key: STAFF_USERS_JSON
  • Value: 위 설정값 전체 붙여 넣기
  • Secret: 체크 → Add variable and deploy
직원 계정이 이미 등록되어 있다면 이 값만으로 덮어쓰지 마세요. 이 도구는 첫 관리자 계정용입니다. 비밀번호와 설정값을 채팅이나 공개 저장소에 올리지 마세요.
