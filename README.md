# OBOK Foods Official English Website

최종 업데이트: 2026-07-20

## GitHub 업로드 방법
1. 이 ZIP 파일의 압축을 풉니다.
2. 압축을 푼 폴더 안의 `index.html`, `.nojekyll`, `assets` 폴더, `README.md`를 모두 선택합니다.
3. GitHub 저장소 `obokfood1.github.io`의 최상위 화면에서 **Add file → Upload files**를 누릅니다.
4. 기존 파일이 있더라도 그대로 업로드하고 **Commit changes**를 누릅니다.
5. Actions 또는 Deployments의 초록색 체크를 확인한 뒤 사이트를 새로고침합니다.

주의: ZIP 파일 자체를 GitHub에 올리면 홈페이지가 변경되지 않습니다.
