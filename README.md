# OBOK Foods English Website

This folder is ready for GitHub Pages.

## Upload
1. Open the `obokfood1.github.io` repository.
2. Upload **the contents of this folder**. Do not upload the ZIP file itself.
3. Click **Commit changes**.
4. Open `https://obokfood1.github.io` after 1–5 minutes.

## Files that must be at repository root
- `index.html`
- `assets/`

## Editing contact details
Open `index.html`, search for:
- `sjnoh@obok.co.kr`
- `Head Office`
- `Jangyu Plant`
- `Jinyeong Plant`

## Images
This first version uses lightweight local CSS illustrations, so it works without Google image servers and avoids the Safari image-loading issue. Real company and product photographs can be added later as local JPG files inside `assets/images/`.
